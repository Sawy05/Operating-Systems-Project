# Operating Systems Algorithms Project

This project implements fundamental Operating System algorithms using Python and Jupyter Notebook.

## Implemented Algorithms

### CPU Scheduling
- Round Robin Scheduling

### Memory Allocation
- Best Fit Memory Allocation

### Page Replacement
- Least Recently Used (LRU)

---

## Features

- Dynamic user input (no hardcoded values)
- Step-by-step execution
- Gantt Chart generation
- Performance calculations
- Fragmentation analysis
- Page fault tracking
- Graphical visualization using Matplotlib
- Algorithm comparison and analysis

---

## Technologies Used

- Python 3
- Jupyter Notebook
- Matplotlib
- Tabulate
